Política de privacidade

Este site coleta o mínimo de dados possível. Aqui está, em linguagem simples, o que é coletado, para quê, e como você pode pedir para ver ou apagar os seus dados, de acordo com a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

Quem é o responsável

Priscila Andrade, fotógrafa e videomaker, com atendimento em Itapema, Balneário Camboriú, Porto Belo e região.

Para qualquer assunto sobre os seus dados, escreva para priscilaandradefoto@gmail.com.

O que é coletado

Contato: este site não tem formulário. Quando você chama pelo WhatsApp, por e-mail ou pelo Instagram, a conversa acontece no aplicativo de cada um, com as regras de privacidade dele. Os dados que você enviar (como nome, telefone e a mensagem) são usados só para responder ao seu pedido.

Visitas ao site: se você aceitar os cookies, o Google Analytics registra dados de navegação de forma agregada (páginas vistas, tempo no site, cidade aproximada, tipo de aparelho e de onde você veio). Nada disso identifica você pelo nome.

Cookies

O site pode usar cookies de medição do Google Analytics, e só depois que você clica em “Aceitar” no aviso. Se você recusar, nenhum cookie de medição é gravado. A sua escolha fica guardada apenas no seu navegador.

Com quem os dados são compartilhados

Apenas com os serviços que fazem o site funcionar: o GitHub (hospedagem), o Vimeo (vídeos dos projetos, carregados quando você abre um projeto), o Google Fonts (fontes do site) e o Google Analytics, se aceito. Esses serviços podem receber o seu endereço de IP para entregar o conteúdo. Os dados não são vendidos nem usados para propaganda.

Por quanto tempo

Conversas de orçamento ficam guardadas enquanto houver diálogo sobre o projeto e, depois, por até 6 meses. Os dados do Google Analytics seguem o prazo configurado na ferramenta, de até 14 meses.

Os seus direitos

Você pode, a qualquer momento, pedir para saber quais dados seus existem, corrigir, apagar ou retirar o seu consentimento. É só escrever para priscilaandradefoto@gmail.com. A resposta vem em até 5 dias.
